# EchoKeys

Windows 鼠标键盘操作录制与原速回放工具。支持当前任务本地保存和重启恢复，不提供文件导入或多任务管理。

## 在 Windows 运行

使用 Windows 10 / 11 和 Python 3.11 或以上版本。安装 Python 时保留默认的 Tcl/Tk 组件。建议使用 Python 3.12。

在项目目录打开终端：

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m echokeys
```

安装后也可以双击 `start-windows.bat`。未安装依赖时请先完成上述命令。

## 使用

1. 点击「开始录制」，在 3 秒倒计时内切换到目标窗口。
2. 执行鼠标移动、左右键点击或双击、键盘按键与组合键；按 ESC 结束录制。
3. 点击「单次测试回放」，倒计时后执行一遍。测试不读取循环设置。
4. 设置循环次数与轮间隔，点击「开始循环回放」。间隔只在两轮之间发生，末轮结束不等待。
5. 点击「保存任务」，保存当前记录和循环设置；下次启动自动恢复，不自动执行。

**按 ESC 随时停止**：倒计时、录制、测试、回放和轮间等待均可停止。也可以点击「停止」按钮。停止后保留记录。开始新录制需要确认覆盖，取消新录制倒计时会保留旧记录。

循环次数默认为 1，必须为正整数。间隔默认为 1 秒，允许 0 和小数。例如录制时长 10 秒、循环 3 次、间隔 2 秒，回放约耗时 34 秒，另加启动倒计时 3 秒。

录制时长包含第一条操作之前和最后一条操作之后、按 ESC 之前的等待。录制结束时仍按住的键会补上释放操作。拖拽手势被丢弃，滚轮、中键和额外鼠标按钮不录制，ESC 不进入记录。

## 本地保存

仅保留一份当前任务，点击「保存任务」替换本地已保存任务。有未保存修改时，关闭窗口会询问是否保存。任务保存在：

```text
%LOCALAPPDATA%\EchoKeys\task.json
```

保存内容包括原始输入事件、时间戳、录制时长和循环设置。使用临时文件原子替换，保存失败保留上一次文件。文件损坏会提示错误，仍可重新录制；不会自动执行文件中的任务。录制及保存均在本地，不需要网络。

## 使用条件

- 使用屏幕绝对坐标。录制与回放时保持窗口位置、分辨率、缩放比例和多显示器布局相同。
- 使用相同的键盘布局、输入法与目标应用状态；本工具回放按键，不对文字内容做识别。
- 系统权限会影响输入注入；需要操作管理员窗口时，以相同权限运行 EchoKeys。UAC 安全桌面、锁屏以及拦截模拟输入的应用不保证可用。
- 鼠标拖拽、滚轮、文件导入、步骤编辑、变速、无限循环、定时执行和多任务管理不在第一版范围内。
- Windows 输入与显示缩放接入参考 [pynput 键盘文档](https://pynput.readthedocs.io/en/latest/keyboard.html)、[鼠标文档](https://pynput.readthedocs.io/en/latest/mouse.html) 和 [平台限制](https://pynput.readthedocs.io/en/latest/limitations.html)。

## 打包 EXE

在 Windows 本机双击 `build-windows.bat`。脚本安装打包依赖、运行测试，再生成 `dist\EchoKeys.exe`。用户运行生成的 EXE 时无需另装 Python。

也可执行：

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --name EchoKeys --collect-submodules pynput run.py
```

不能在 macOS 上直接构建经过验证的 Windows EXE。本项目当前提供源码和 Windows 构建脚本，Windows 集成与打包验收需在 Windows 完成。

## 开发验证

Mac 可以在项目目录直接运行以下单元测试，无需创建虚拟环境、安装依赖或授予辅助功能/输入监控权限：

```sh
python3 -m unittest discover -s tests -v
```

新增测试覆盖三个入口的倒计时取消、前后等待、分数秒及零间隔、发送耗时不累积漂移、ESC 中断时释放按键与鼠标、拖拽后的有效点击、组合键顺序、保存写入失败和退出保存选择。计时测试使用虚拟时钟，不需要真实等待 3 秒或实际回放。

核心测试不加载全局输入监听，也不需要安装 pynput 或启动图形界面：

```sh
python3 -m unittest discover -s tests -v
python3 -m compileall echokeys tests run.py
```

测试使用可控时钟验证次数、原始事件时间、末尾等待及轮间隔，使用可替换输入设备验证异常释放；界面行为测试验证启动限制、覆盖确认与参数处理，不代替真实桌面测试。

## Windows 手工验收

- [ ] 首次启动为待录制，测试与循环按钮禁用。
- [ ] 录制、测试、循环三个入口均显示 3 秒倒计时，倒计时操作不计入录制。
- [ ] 在记事本录入文字并使用 Shift、Ctrl+A 等组合键，回放顺序及速度一致。
- [ ] 录制鼠标路径、左右点击与双击，保持目标窗口位置，回放结果一致；多屏负坐标与缩放分别验收。
- [ ] 拖拽与滚轮不回放；录制前按住、开始后松开的按键不形成孤立输入。
- [ ] 单次测试固定一遍，即使循环设置为 10 次或字段中有无效值。
- [ ] 约 10 秒记录循环 3 次、间隔 2 秒，倒计时后约 34 秒完成，最后无等待；另验收间隔 0、0.25。
- [ ] 录制、三个倒计时、测试、回放事件等待和轮间等待分别按 ESC，立即停止且后续动作不执行。
- [ ] 回放按住 Ctrl、Shift 或鼠标按钮时按 ESC，停止后键鼠无持续按住；关闭窗口同样释放。
- [ ] 任务执行中三个启动按钮和循环参数禁用。
- [ ] 拒绝覆盖或在新录制倒计时按 ESC，旧记录仍可回放。
- [ ] 保存后关闭并重启，记录与设置恢复，不自动回放；没有导入入口。
- [ ] 未保存时关闭窗口分别验证保存、放弃、取消；文件损坏提示后仍可录制。
- [ ] 打包后的 EXE 在未安装 Python 的 Windows 机器上完成以上流程。
