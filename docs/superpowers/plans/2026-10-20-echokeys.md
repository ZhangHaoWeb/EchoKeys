# EchoKeys Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 交付可在 Windows 启动的鼠标键盘录制与原速循环回放桌面工具。

**Architecture:** Python 标准库 Tkinter 构建中文界面，pynput 接入 Windows 全局输入监听与模拟。使用独立的录制模型、可取消执行引擎和输入适配器，界面仅通过消息队列与工作线程交换状态；单调时钟保证事件时间戳不受系统时间变化影响。

**Tech Stack:** Python 3.11+、Tkinter、pynput、unittest；PyInstaller 用于 Windows 本地打包。

**Spec:** `docs/requirements.md`

## Global Constraints

- Windows 桌面应用；当前开发机为 macOS，真实 Windows 输入验收必须单列为未验证事项。
- 三个入口固定倒计时 3 秒；ESC 全局停止且不进入录制。
- 循环次数默认 1、正整数；间隔默认 1 秒、允许 0 和小数；最后一轮不等待。
- 不录制拖拽、滚轮；鼠标使用绝对屏幕坐标；保留原速。
- 仅一份当前任务，支持本地保存录制与循环设置及重启恢复，不支持文件导入；恢复后不自动执行。取消新录制倒计时不覆盖旧记录；活动阶段启动操作互斥。

## Review Focus

- 间隔 NaN、无穷大、负数以及非整数次数必须拒绝，不能启动工作线程。
- 取消倒计时、事件等待和轮间等待时，不得再执行后续输入。
- 模拟按键按住时发生异常或退出，必须逐项尝试释放，单项失败不能跳过其余释放。
- 按住鼠标移动不得形成拖拽回放；仅在释放位置仍相同时保存成对点击，双击保留原始时间间隔。
- 停止录制时仍按住的键必须补齐释放；忽略录制开始前已按住键的孤立释放。
