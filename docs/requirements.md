# EchoKeys 第一版需求

开发 Windows 鼠标键盘操作录制与回放桌面工具，仅管理当前一份任务，支持本地保存和重启恢复，不支持文件导入。

- 记录鼠标绝对坐标移动、左右键单击与双击、键盘按下与松开（含组合键），保留原始操作间隔与录制时长。
- 不支持拖拽、滚轮；ESC 为全局控制键，不进入记录。
- 开始录制、单次测试、循环回放均先倒计时 3 秒；按钮点击不计入录制。
- 测试固定执行一次，不受循环参数影响。
- 循环次数为正整数，默认 1；间隔为有限非负秒数，支持小数，默认 1 秒。
- 仅在两轮之间等待，最后一轮结束不等待。10 秒记录执行 3 次、间隔 2 秒，总时长约 34 秒，不含倒计时。
- 任意活动阶段按 ESC 立即中止；录制停止保留已录内容；回放停止保留原记录。
- 录制与回放互斥，执行期间禁用所有启动按钮；没有有效记录禁用回放。
- 覆盖旧记录需确认；新录制倒计时取消时必须保留旧记录。
- 停止时取消剩余事件与轮次，释放工具模拟按住的键与鼠标按钮。
- 界面提供三个启动按钮、次数与间隔输入、状态、录制时长、当前轮次／总次数及固定提示「按 ESC 随时停止」。
- 状态覆盖待录制、倒计时、录制中、待回放、测试中、循环回放中、循环等待中。
- 用户需保持目标窗口位置、分辨率和缩放比例一致。
- 支持将当前录制记录、循环次数和循环间隔保存到本机；重启后恢复，但不自动开始回放。不提供文件导入功能。
- 不实现多任务管理、步骤编辑、图像识别、变速、无限循环或定时执行。

验收：原速准确回放移动、点击与组合键；次数及间隔准确；三个入口均有倒计时；所有活动阶段 ESC 可中止且无后续动作；停止后无模拟输入持续按住。
